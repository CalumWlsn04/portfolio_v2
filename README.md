# Calum Wilson Portfolio v2

A hiring-focused portfolio built with React, Vite, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Before deploying

1. Verify the email address in `src/App.jsx` inside the `socials` object.
2. Add a resume PDF to `public/` and link it in the header if desired.
3. Add project repository or live-demo URLs when those projects can be shared publicly.
4. Create an Open Graph preview image and add `og:image` and `twitter:image` metadata in `index.html`.

## Deploy

The generated `dist/` folder can be deployed to Vercel, Netlify, Cloudflare Pages, GitHub Pages, or any static host.

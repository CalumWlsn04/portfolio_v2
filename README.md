# Calum Wilson Portfolio v2

A React/Vite engineering portfolio organized around three featured case studies:

- Cancer Nuclei Classification
- JetTrack Data Pipeline
- Breeze Pricing Intelligence Platform

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

# Stage 2 — Professional Portfolio Foundation

This archive is a complete replacement for the Stage 1 project folder.

## Included

- Rewritten homepage narrative covering AI, data, backend, cloud, and product engineering
- Separate Featured Work, Experience, Additional Projects, About, and Contact sections
- Featured case studies for Cancer Nuclei Classification, JetTrack, and Breeze
- Reusable metric, architecture, approach, and lesson sections
- Responsive layouts and new project visuals
- Full computer vision report included under `public/`

## Apply

1. Back up your current folder or commit it to Git.
2. Copy this archive's contents into the project root.
3. Run `npm install`.
4. Run `npm run dev`.
5. Validate with `npm run build` and `npm run lint`.

The generation environment could not install `react-router-dom` from its internal npm mirror, so the final Vite build must be validated locally.
